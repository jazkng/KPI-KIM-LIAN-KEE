# 日报天气、营业额组成与视觉增强

本地交互稿，所有金额与天气为演示，不调用天气服务或正式数据库。

- 结算天气按所选营业日显示，2026年10月12–18日有明确模拟天气；其他月份没有记录就显示未记录，不以当前天气冒充历史天气。
- 该月最后结算日有渠道拆分示例。店内深炭色、外卖金色；Grab绿色、Foodpanda粉色、ShopeeFood橙色作为渠道识别色。
- 分段条及比例使用 deliveryRecord 中同一金额，店内+外卖=当日营业额。渠道占比按总营业额计算；均价读取同一渠道销售额。
- 无分渠道资料的日期不画模拟比例替代，明确无资料。0销售渠道显示0.0%。
- 配色提升为暖白、深炭色与金色选中态，日报金额区深底、KPI金色分隔，组成区有单独层级。红色保留用于异常，不靠颜色单独传递含义。
- 日报仍只读，管理端录入不变。

已检查：JS语法通过；浏览器确认10/18大雨演示、10/12晴演示、9月天气未记录；店内9200/11280=81.6%，外卖2080/11280=18.4%；分平台Grab1400=12.4%、Foodpanda680=6.0%、ShopeeFood0=0%；无渠道资料日不显示组成条；手机无横向溢出；日报渠道输入框数量仍为0。

正式整合优先沿用结算记录已有天气字段；如要接入历史天气API，来源、门店位置、营业时段和失败状态需另核对。此稿没有更改ERP报表或真实历史天气。
