# 近7天对比、每日保本与精简呈现

本轮仍只修改独立交互稿，不连接真实财务或库存，不更改CC分支、ERP应用或开发站。

## 保留的内容

- 近7天与前7天按星期对齐，金色/灰蓝分组柱、两期合计、差额和比例；点击柱子查看当日日报。
- 所选月每日已结算营业额＋保本暂估虚线，数字/状态卡、表格切换。当前演示月份的未结算日以空心红虚线提示，不计0。
- 日报天气、营业额组成、各平台完成单与平均单价继续保留，日报只读。

## 精简方式

平台信息改成渠道/营业额/完成单/均价紧凑四列；解释折叠在查看说明、均价怎么算、保本线怎么算中。删除与整月资料衔接的长卡片，换成两个跳转。演示标签保留顶部一次，重复页尾角色/数据库说明删除；待补、未记录、暂估等影响判断的状态不隐藏。

## 共用模拟数据与保本假设

各月逐日演示数由固定权重分配，保持最后7日已用的样例数不变，上一周同日数对应样例d.previous，并保证整月日数之和等于该月营业额。不是正式日结数据，不能把这段演示分配方式带入ERP。

模拟保本采用现有 breakEvenSim 的固定成本/贡献率思路：人工+其他费用为期内固定成本，食材采购+平台为变动成本，按期内已结算天数日均推算整月固定成本，除以贡献率与演示全月营业天数。本稿以日历天作为营业天数的显式假设。正式实现必须复用已核对的ERP保本结果和营业天数，不能把全部开销无条件视作固定成本。贡献率<=0时不显示保本数。

这是同一组样例推导的暂估线，超过线不代表最终月结已确认盈利。它不是第二套真实账目算法。
