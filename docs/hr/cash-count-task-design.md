# 收银点钱任务（任务类型 CASH）

> 负责人 2026-10-24 批准：面额照建议、一天一次、只是记录（不接日结、不提醒），派给谁由派任务的人决定。

## 做法
- 派任务时多一个类型「收银点钱」，次数预设「每日」，派给谁照一般任务（指定员工或整个部门）。
- 员工打开任务：
  1. **上班**：按面额填张数 / 个数（RM100、50、20、10、5、1；50、20、10、5 仙），系统自动算合计 →「保存上班金额」。下班点钱之前可以重新保存。
  2. **下班**：再打开同一个任务，看到上班金额，按面额点下班的钱 →「下班点完，交回」。
- 管理层在任务管理打开这个任务：看到当天上班 / 下班 / 本班增加，以及**最近 31 天每天的记录**（点开看面额明细、谁点的、几点）。确认或退回照一般任务。

## 资料
- 新集合 `cash_counts/{日期}_{任务 ID}`：`opening` / `closing`（面额张数、合计〔仙〕、谁、几点）、`diffSen`。每天一笔，**永久保留**（重复任务本身每天会被下一期覆盖，所以金额另存）。
- 任务交回时 `submission.cash = { openingSen, closingSen }`（选填新字段）。
- 金额一律用「仙」整数计算，没有小数误差。
- 只新增集合与选填字段；不改日结、不改财务记录。V1 不读这些资料。

## 不包含
- 不接日结、不自动带入开店 / 收店现金、不发差额提醒（负责人决定）。
